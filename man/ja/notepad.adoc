== NAME

notepad - 簡易グラフィカルメモ帳

== SYNOPSIS

*notepad*

== DESCRIPTION

*notepad* は、bas+ UI アーキテクチャ（action/group モデルによるメニューバー／ツールバー）で構築された、シンプルなグラフィカルテキストエディタです。

ファイル（新規、開く、保存、名前を付けて保存、終了）と編集（切り取り、コピー、貼り付け）のメニューおよびツールバーを提供します。
