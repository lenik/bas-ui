== NAME

notepad - simple graphical notepad

== SYNOPSIS

*notepad*

== DESCRIPTION

*notepad* is a minimal graphical text editor built with the bas+ UI architecture (menubar/toolbar from action/group models).

It provides File (New, Open, Save, Save As, Exit) and Edit (Cut, Copy, Paste) menus and a toolbar.
